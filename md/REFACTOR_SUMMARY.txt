💡 PROBLEMAS PRINCIPAIS IDENTIFICADOS
═══════════════════════════════════════════════════════════════════════════════

1. DUPLICAÇÃO DE DIALOGS & MODAIS
   │
   ├─ 15+ implementações de "create/edit" dialog
   ├─ Cada uma reimplementa: form validation, loading, error handling
   ├─ Dialogs inline em .map() loops (15 casos)
   │
   └─ ✅ SOLUÇÃO: <FormDialog>, <ConfirmDialog>, <InfoDialog> genéricos

2. FORM FIELDS REPETIDOS
   │
   ├─ Input, Select, Date, Textarea implementados inline
   ├─ Validação errors inconsistente
   │
   └─ ✅ SOLUÇÃO: <FormField> genérico reutilizável

3. CARDS SEM PADRÃO
   │
   ├─ 10+ estilos CSS diferentes
   ├─ Inconsistência visual
   │
   └─ ✅ SOLUÇÃO: <BaseCard variant="default|stat|highlight|action">

4. LISTAS/TABELAS REPETIDAS
   │
   ├─ 10+ páginas reimplementam sort, filter, pagination
   ├─ Código duplicado em cada listagem
   │
   └─ ✅ SOLUÇÃO: <DataTable> genérico com hooks reutilizáveis

5. TIPOS ESPALHADOS
   │
   ├─ Types em app/, components/, Prisma schema
   ├─ Duplicação de interfaces
   │
   └─ ✅ SOLUÇÃO: lib/types/ centralizado

6. HOOKS DUPLICADOS
   │
   ├─ useForm em vários módulos
   ├─ Falta padrão de server action wrapper
   │
   └─ ✅ SOLUÇÃO: lib/hooks/ consolidado
