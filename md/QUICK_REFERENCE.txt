DÚVIDAS FREQUENTES
────────────────────────────────────────────────────────────────────────────────

P: Por onde começo?
R: Comece com FILE SPLITTING de action files (mais simples).
   settings/actions.ts é perfeito para aprender padrão.

P: Quanto tempo leva?
R: 20-30 dias para refactor COMPLETO (4 pilares).
   Quick wins: 3-5 dias (SubmitButton, useMutation, Zod).

P: Preciso fazer tudo?
R: Não! Comece com FILE SPLITTING + QUICK WINS.
   Depois evolua para componentes compartilhados.

P: Como não quebro nada?
R: Cada mudança = novo commit.
   Rodar tsc + lint antes de commitar.
   Testes passam? Commit. Não passa? Desfaz.

P: Meu projeto fica quebrado durante refactor?
R: Não! Você não quebra imports (re-exports em index.ts).
   Cada passo é atômico e testável.
