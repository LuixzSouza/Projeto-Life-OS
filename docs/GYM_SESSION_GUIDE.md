# 🏋️ Guia Completo: Como Usar a Sessão de Treino

> Este guia é para **leigos e iniciantes**. Se você não entende termos técnicos, leia isto antes de treinar!

---

## 📱 Interface da Sessão

A sessão de treino tem **3 fases**:

### 1. **Setup (Preparação)** - "Qual treino vou fazer?"
Você escolhe:
- Uma **ficha salva** (ex: "Push/Pull/Legs")
- Uma **rotina** (exercícios personalizados)
- Ou começar do **zero** (adicionar exercícios na hora)

**O que você vê:** Lista de exercícios que vai fazer hoje.

---

### 2. **Active (Treinando)** - "Vou fazer os exercícios"
Aqui você registra cada série que faz.

**Estrutura do que você vê:**
```
┌─────────────────────────────┐
│  EXERCÍCIO: Supino          │
│                             │
│  Série 1 [  ] Kg [  ] Reps  │
│  Série 2 [  ] Kg [  ] Reps  │
│  Série 3 [  ] Kg [  ] Reps  │
│                             │
│  [⏱️ DESCANSO] [📱 PRÓXIMO]  │
└─────────────────────────────┘
```

---

### 3. **Summary (Resumo)** - "Como foi?"
Você registra:
- **Foto do treino** (opcional, legal pra motivação!)
- **Sensação** (fácil, ok, difícil)
- **Notas pessoais** (problema de técnica, dor, mudança de carga)

Tudo salva automaticamente no banco! 📊

## 🎯 Como Registrar Uma Série

### Passo 1: Digite o PESO
```
O que significa?
  = Quanto de carga você levantou (em kg ou libras)

Exemplos:
  ✅ Fez 10 reps com 20kg → Digite 20
  ✅ Fez 15 reps com barra vazia → Digite 0 (ou deixe em branco)
  ✅ Fez 8 reps de rosca com 8kg em cada mão → Digite 16 (total)

Não tem peso exato?
  = Aproxime! 10.5kg? Digite 10 ou 11, não faz diferença gigante.
```

### Passo 2: Digite as REPS (Repetições)
```
O que significa?
  = Quantas vezes você levantou o peso

Exemplos:
  ✅ Fez 10 repetições → Digite 10
  ✅ Fez 12 reps → Digite 12
  ✅ Fez 8 reps mas poderia fazer mais → Digite 8 (o que FEZ, não o que poderia)

Importante:
  ❌ Não coloque "até" falhar ou "próximo a falhar"
  ✅ Coloque a quantidade REAL que conseguiu fazer
```

### Passo 3 (Opcional): RPE ou RIR - Intensidade da Série
```
O QUE SÃO?
  RPE = "Escala de Esforço Percebido" (1-10)
  RIR = "Repetições em Reserva" (0-10)

QUAL USAR?
  → Escolha UM, aquele que faz mais sentido pra você
  → Ambos medem a mesma coisa: "quão intenso foi?"

┌─────────────────────────────────────────┐
│ RPE (ESCALA DE ESFORÇO 1-10)           │
├─────────────────────────────────────────┤
│ 1-2 | Muito fácil, sem cansaço        │
│ 3-4 | Fácil, com margem                │
│ 5-6 | Moderado, sentindo o trabalho    │
│ 7-8 | Difícil, cansativo               │
│ 9   | Bem intenso, quase no limite     │
│ 10  | No limite máximo, não conseguiria mais │
└─────────────────────────────────────────┘

EXEMPLOS:
✅ Fez 10 reps e poderia fazer 10 MAIS → RPE 5 ou RIR 10
✅ Fez 10 reps e poderia fazer 3 MAIS → RPE 7 ou RIR 3
✅ Fez 10 reps e é tudo que conseguia → RPE 10 ou RIR 0

┌─────────────────────────────────────────┐
│ RIR (REPS EM RESERVA - 0-10)          │
├─────────────────────────────────────────┤
│ 0 | No limite, não consegue mais       │
│ 1-2 | Bem intenso, quase chegou lá    │
│ 3-5 | Moderado, ainda tem margem      │
│ 5-10 | Tranquilo, com bastante margem │
└─────────────────────────────────────────┘

QUAL VOCÊ DEVERIA USAR?
┌────────────────────────────────┐
│ RPE = melhor para iniciantes   │
│ (Mais fácil: "era difícil?")   │
│                                │
│ RIR = melhor para experientes  │
│ ("Quantas reps MAIS fariam?")  │
└────────────────────────────────┘

NÃO SEI O QUE COLOCAR?
→ Deixe em branco! Ambos são OPCIONAIS.
→ O importante é o peso × reps
```

### Passo 4: Clique no ✓ "Série Feita"
```
✅ Marca a série como completa
🔔 Pode aparecer um som/vibração de celebração
```

## ⏱️ Descanso Entre Séries

### O App Sugere um Tempo
```
Exemplo:
  ┌─────────────────────┐
  │ ⏱️ DESCANSANDO       │
  │                     │
  │ Próxima série: 2:15 │
  │                     │
  │ [PULAR] [ESTENDER] │
  └─────────────────────┘

O que isso significa?
  = O app recomenda 2min15seg de descanso entre séries

Por que?
  → Músculo forte = precisa de mais descanso (2-3 min)
  → Resistência = menos descanso (30-60 seg)
  → O app escolhe baseado no que você selecionou na ficha

Preciso respeitar?
  ❌ NÃO é obrigatório
  ✅ MAS é recomendado para melhor resultado
  💡 Respeitando descanso = músculos recuperam = próxima série melhor

Posso fazer diferente?
  ✅ SIM! O app deixa você:
     → Pular descanso (botão PULAR)
     → Estender mais (botão ESTENDER)
```

## 📊 Tipo de Série

Ao lado do peso/reps, tem uma aba de TIPO:

```
SÉRIE NORMAL (padrão)
  = Aquela mesma, contar 1 série

WARMUP (aquecimento)
  = Série leve para esquentar o músculo
  → Antes das séries pesadas
  → Não conta pro volume total
  → Não pesa no treino

DROPSET (série reduzida)
  = Faz as reps, depois reduz o peso e faz mais
  → Exemplo: 10 reps com 20kg, depois 10 mais com 10kg
  → Conta como série!

OUTROS: Amrap, Last, etc.
  = Tipos específicos, não se preocupe se não entender
```

## 🎯 Por Que Registrar TUDO?

### Razão 1: Evolução
```
Semana 1: Supino 10 reps com 20kg
Semana 2: Supino 10 reps com 22kg ← Ficou mais forte!
Semana 3: Supino 12 reps com 20kg ← Ficou mais resistente!

SEM registrar = não vê progresso
COM registrar = vê claramente que está melhorando
```

### Razão 2: Não Esquecer
```
"Qual era a carga da semana passada?"
  → App mostra no histórico!

Sem isso:
  ❌ Começa do zero toda sessão
  ❌ Nunca sobrecarrega progressivamente
  ❌ Treina no piloto automático

Com histórico:
  ✅ Sabe exatamente o que fazer
  ✅ Tenta melhorar (mais peso ou mais reps)
  ✅ Construir músculos = necessário!
```

### Razão 3: Padrão de Ganho
```
Treinar 2 meses sem padrão:
  ❌ Sem melhor (não evoluiu)

Treinar 2 meses registrando:
  ✅ 20% mais forte
  ✅ Músculo desenvolvido
  ✅ Progressão clara

Por que funciona?
  = Progressão: aumentar carga ou reps todo mês
  = Consistência: repetir o mesmo treino
  = Registro: saber o que fez antes
```

## 💾 Dados Salvos

### Onde fica tudo?
```
LOCAL NO SEU CELULAR (localStorage)
  ✅ Rápido
  ✅ Funciona SEM internet
  ❌ Se perder o celular, perde dados

NA NUVEM (Banco de Dados Remoto)
  ✅ Seguro
  ✅ Sincroniza com outro celular/PC
  ✅ Backup automático
  ✅ Funciona mesmo mudando de aparelho
```

### Quando salva?
```
Automático ao finalizar sessão:
  1. Você clica "Encerrar Treino"
  2. App mostra resumo
  3. Você clica "Salvar"
  4. Tudo envia para a nuvem

Sem internet?
  ✅ Fica salvo no celular
  ✅ Sincroniza quando voltar a internet
  ✅ Sem perda de dados
```

## 🚀 Dicas para Leigos

### Dica 1: Primeira Série é de Teste
```
Não tem certeza do peso?
  → Comece leve (20kg, por exemplo)
  → Veja se consegue 12 reps
  → Se foi fácil, próxima série aumenta para 25kg
  → Se foi difícil, próxima série reduz para 15kg

O app mostra a carga anterior:
  "Supino: última vez 20kg, você fez 10 reps com 20"
  → Comece com isso!
```

### Dica 2: Não Precisa ser Perfeito
```
Não tem disco de 22.5kg?
  → 20kg também funciona!

Não conseguiu os 10 reps?
  → Digite o número que CONSEGUIU!

Não sabe o RPE exato?
  → Deixe em branco

O importante = PESO × REPS
  (Outros dados ajudam, mas não são críticos)
```

### Dica 3: Fotos Motivam!
```
Depois de terminar:
  → Tire uma selfie ou foto do treino
  → App salva na galeria do app
  → Ver a série de fotos = muito motivador!

"Vejo que treinei 60 dias = photo evidence de progresso"
```

### Dica 4: Anote Problemas
```
Teve dor no ombro?
  → Use o campo NOTAS: "dor no ombro"

Reduziu a carga?
  → "reduzi por segurança"

Técnica estranha?
  → "revisar forma"

Ajuda você E seu instrutor a entender o padrão
```

### Dica 5: Use MODO FOCO (não lista)
```
2 Visualizações:
  
MODO LISTA (vê todos exercícios):
  ✅ Visão geral do treino
  ❌ Distrativo, muita informação

MODO FOCO (um exercício por vez):
  ✅ Sem distrações
  ✅ Menos "bagunça" visual
  ✅ Melhor para treinar

Recomendação: Use FOCO durante o treino!
```

## ❌ Erros Comuns

| Erro | Por que não? | Solução |
|------|-------------|--------|
| Colocar "até falhar" em reps | Não é número real | Coloque quantidade REAL que fez |
| Deixar tudo em branco | App não consegue rastrear | Mínimo: peso + reps |
| Esquecer de salvar no final | Treino não fica registrado | Sempre clique "Salvar" ao final |
| Usar RPE E RIR juntos | Redundante, confunde | Escolha UM |
| Esperar descanso perfeito | Descanso é orientativo | Se puder esperar mais, espera; senão, pula |

## 🎓 Aprenda Mais

### Conceitos Importantes

**Progressão Progressiva (chave do ganho!)**
```
Semana 1: 10 reps com 20kg
Semana 2: 11 reps com 20kg
Semana 3: 12 reps com 20kg
Semana 4: 10 reps com 22kg ← Aumenta peso, reps caem (normal!)
Semana 5: 12 reps com 22kg

Padrão: aumenta peso quando consegue 12 reps
```

**Volume (músculos crescem com volume)**
```
Volume = Peso × Reps × Séries

Exemplo:
  20kg × 10 reps × 3 séries = 600kg total
  
Semana que vem:
  22kg × 10 reps × 3 séries = 660kg total ← Mais volume = mais ganho
```

**RPM (Ritmo de Execução)**
```
Não precisa ser rápido!
  Lento = 3 seg descendo + 1 seg subindo
  
Lento gera mais dano muscular = mais crescimento
  (você sente muito a série!)
```

## 🎯 Resumo Executivo (TL;DR)

1. **Digite peso** = quanto você levantou
2. **Digite reps** = quantas repetições
3. **RPE/RIR (opcional)** = quão difícil foi (deixe em branco se não souber)
4. **Clique ✓** = série feita
5. **Descanse** = tempo sugerido é recomendado
6. **Repita** para próxima série e exercício
7. **Finalize** = foto + sensação + notas (opcionais)
8. **Salve** = tudo fica registrado
